# 统计学基础概念

> 笔记日期：2026-09-03

## 1. 什么是统计学

统计学是收集、整理、分析、解释数据，并从中得出结论的科学。它可以分为两大类：

- **描述性统计（Descriptive Statistics）**：对数据进行整理、总结和展示，如求均值、绘制图表。
- **推断性统计（Inferential Statistics）**：根据样本数据去推断总体特征，如假设检验、置信区间。

## 2. 总体与样本

| 概念 | 含义 | 示例 |
|------|------|------|
| 总体（Population） | 研究对象的全体 | 全校所有学生 |
| 样本（Sample） | 从总体中抽取的一部分 | 随机抽取的 200 名学生 |
| 参数（Parameter） | 描述总体的数值 | 全校平均身高 |
| 统计量（Statistic） | 描述样本的数值 | 样本平均身高 |

## 3. 变量类型

```
变量
├── 定性变量（分类）
│   ├── 名义变量：无顺序（性别、血型、颜色）
│   └── 有序变量：有顺序（学历、满意度等级）
└── 定量变量（数值）
    ├── 离散变量：可数（人数、次数）
    └── 连续变量：可测（身高、温度、时间）
```

## 4. 描述性统计核心指标

### 集中趋势（数据集中在哪）

- **均值（Mean）**：所有数据之和除以个数，易受极端值影响。
- **中位数（Median）**：排序后位于中间的值，抗极端值。
- **众数（Mode）**：出现次数最多的值。

### 离散程度（数据分散程度）

- **极差（Range）**：最大值 − 最小值。
- **方差（Variance）**：各数据与均值之差的平方的平均。
- **标准差（Standard Deviation）**：方差的平方根，与原始数据同单位，最常用。

### 分布形状

- **偏度（Skewness）**：描述分布是否对称。
- **峰度（Kurtosis）**：描述分布的尖峭程度。

## 5. 小结

- 拿到数据先判断变量类型，再选择合适的统计方法。
- 描述性统计是数据分析的第一步，能帮我们快速了解数据全貌。
- 均值 + 标准差是最常用的"数据画像"组合。
